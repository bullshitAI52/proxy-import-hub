# Proxy Import Hub · 统一导入分享页

[English](README_EN.md)

**这是一个新仓库，尚未部署。旧 Surge、v2rayN 仓库、线上服务、已有链接均未修改。**

## 大白话流程
管理员输入管理密钥 → 粘贴 HTTPS 订阅或节点链接 → 生成私有分享网页 → 朋友打开网页 → 选择自己使用的软件导入。

## 可视化管理界面
粘贴后点“生成分享网页”，系统会自动识别内容，成功时显示“识别格式、节点数和注意事项”，无需手选格式。支持普通节点列表、标准/URL-safe Base64 和基础 Clash YAML；链接返回登录网页、空内容、无效编码、Surge/圈 X 完整配置时会提示原因。

Clash YAML 输入采用保守支持范围：基础 SS（无插件）、Trojan TCP/TLS、VMess TCP/WS（可带 TLS）。任何节点包含未知字段、VLESS/Reality、gRPC 或其他未支持参数时，整份输入拒绝并指出节点序号，不偷偷删节点。**原始 `vless://` 节点链接仍可透传**，这不代表 YAML 中的 VLESS 已支持，也不代表 Surge 能用 VLESS。HTTPS 源每次更新重新识别；只包含外部 provider 的 YAML 不会被自动抓取。

新首页提供手机自适应的大按钮和三步表单。生成成功后直接点击“复制分享链接”发给朋友，也可以“预览分享页”；历史列表支持复制、打开、撤销。复制权限被浏览器阻止时，会选中地址供手动复制。密钥不保存到浏览器本地存储，刷新后需重新填写。

界面需要配套后端部署后使用，不是直接打开 HTML 文件就能生成有效链接。本次 UI 更新只上传到新仓库，没有部署或改动旧服务。

| 软件 | 当前入口 | 边界 |
|---|---|---|
| Surge Mac / iPhone | URL Scheme 导入按钮 | 协议不兼容时转换失败或省略节点 |
| Shadowrocket 小火箭 | shadowrocket://add/ 按钮 + 复制订阅备用 | 未实机验收，版本和系统可能限制唤起 |
| v2rayN | 复制 HTTPS 订阅，再 Ctrl+V 或手动添加 | 不承诺网页直接唤起所有版本 |
| 圈 X（Quantumult X） | 追加节点资源按钮 + 专用订阅复制 | 需要支持 add-resource 的版本，尚未实机验证 |
| Clash 兼容客户端 | clash:// 导入按钮 + 专用 YAML 订阅复制 | 以 Clash Verge Rev 的协议为依据，并非所有客户端通用，尚未实机验证 |

## 新增：圈 X 和 Clash 怎么用
- 圈 X：打开分享页 → 点“打开圈 X 添加节点订阅” → 在客户端更新节点资源、选择节点。使用 `add-resource` 追加节点，不使用替换已有资源的 `update-configuration`，不安装重写或分流规则。按钮无反应时复制圈 X 专用地址，在客户端添加节点资源。
- Clash：打开分享页 → 点“打开 Clash 导入配置”。客户端需要注册 `clash://`（例如 Clash Verge Rev）。部分版本可能直接导入或启用，先备份原配置。失败时复制 Clash 专用地址，在客户端订阅管理中从 URL 导入，然后选择节点。
- 两种输出都需要独立的本地 subconverter 引擎，当前版本 v0.9.0；转换能力受引擎限制，不支持的协议可能被省略。失败会明确报错，不返回伪装成可用配置的空内容。
- Clash 输出是最小 YAML 配置：端口 7890，禁止局域网连接到代理监听端口；IPv4 局域网目标直连，其余走所选节点。不是原订阅服务商的完整分流规则。圈 X 只输出节点资源。
- 管理入口接受节点 URI / Base64 节点列表、基础 Clash YAML，或返回这些内容的 HTTPS 订阅，**支持基础 SS、Trojan TCP/TLS、VMess TCP/WS 的内嵌 Clash YAML；其他协议和高级参数会拒绝**。不会导入原始配置的规则、DNS、脚本或外部 provider。
- 新入口只更新 GitHub，未部署；路由和格式单元测试不等于转换引擎联调或真实客户端验收。

接口依据：[圈 X 官方 URL Scheme](https://github.com/crossutility/Quantumult-X/blob/master/url-scheme.md)、[Clash Verge Rev URL Schemes](https://www.clashverge.dev/guide/url_schemes.html)、[subconverter 输出格式](https://github.com/tindy2013/subconverter/tree/v0.9.0)。

不会自动点击、绕过客户端确认或替朋友开启 VPN。网页按钮只是提出导入请求，成功生成配置不等于代理实际可用。

## 到底是不是“一键导入”？
**三个软件都有入口，但目前不是三个都已实现、验证了一键导入。**
- Surge：提供点击后唤起软件的导入按钮，需要已安装 Surge，并在软件内确认。新统一项目还没有完成客户端实机验收。
- 小火箭：提供尝试唤起软件的导入按钮，**尚未实机验证**；不能保证所有版本都能打开或接受订阅。
- v2rayN：目前是“复制订阅 → 打开软件 → 粘贴添加”，**不是浏览器一键导入**。

## 管理员怎么用（给朋友发链接的人）
1. 先完成下面的独立部署。GitHub 仓库只是代码，仓库地址不是可直接导入的分享网页；旧 Surge 分享页也不会自动变成三端页面。
2. 打开新部署的管理首页，填写管理密钥。密钥只给管理员用，不发给朋友。
3. 填一个容易认的名称，粘贴 HTTPS 订阅地址，或节点链接／Base64 节点列表。
4. 点击生成，将生成的**私有分享页链接**发给朋友。不要把管理密钥、服务器密码或管理页面当成导入资料发送。
5. 不想继续分享时，在管理页撤销对应分享。已被导入的软件仍可能保存节点；若要停用账号，还需在节点服务端处理。

## 朋友怎么用（不用自己填写节点参数）
先安装对应软件，然后在浏览器打开朋友发来的分享网页。浏览器可能询问是否打开应用，这时选择允许；网页不能替你安装软件或自动批准 VPN 权限。

### Surge（Mac 或 iPhone）
1. 在分享页选择与你设备对应的 Mac 或 iPhone 导入按钮。
2. 浏览器提示打开 Surge 时允许打开，在 Surge 中确认导入配置。
3. 按软件提示选择配置并开启连接；首次使用可能需要批准系统网络权限。
4. 如果没有唤起，先确认软件已安装，可尝试在系统浏览器中打开分享页，再点击按钮。导入后没有可用节点，也可能是源协议不支持 Surge，不是重新点按钮就能解决。

### 小火箭（Shadowrocket）
1. 点击小火箭导入按钮；如果成功打开软件，按提示确认添加订阅。
2. **按钮没反应或添加失败时**，使用网页提供的复制订阅入口，在小火箭中找到订阅添加入口，粘贴地址并保存、更新。具体菜单名称以安装版本为准。
3. 选择节点并开启连接。此入口尚未实机验收，不保证直接点击就能完成导入。

### v2rayN（Windows）
1. 在网页点击复制订阅地址。
2. 打开 v2rayN，在服务器列表处（不要选中输入框）按 Ctrl+V；支持此操作的版本会把 HTTPS 地址作为订阅添加。
3. 如果没有添加，进入订阅管理，新增订阅并粘贴地址、保存，然后更新订阅。
4. 选择节点，再按软件提示开启所需的系统代理或连接模式。**这里仍需粘贴操作，不能宣传成“网页点一下就全部设置好”。**

## 常见情况
- 分享页面打不开：确认新服务已经部署且链接未撤销；私有 GitHub 仓库链接不是分享链接。
- 能导入但不能联网：导入仅负责把配置交给软件，不保证服务器、节点账号、额度、证书或本地网络可用。
- 三个软件的节点数量不同：Surge 转换可能拒绝或省略不支持的协议；另两个入口保留原始节点列表，客户端是否支持仍取决于其版本。
- 把分享链接转发给别人安全吗：拿到链接的人可以读取节点。只私发给可信的人，不贴进公开仓库、论坛或截图。

## 包含什么
- 根目录 server.py / index.html / share.html：统一创建、查看、撤销分享，以及三类客户端入口。
- apps/surge：原 Surge 项目的脱敏源码快照。统一服务复用了其认证、加密、SSRF防护和转换代码，并使用新路径及引擎端口。
- apps/v2rayn：原 v2rayN 项目的脱敏源码快照，包括只读 3x-ui 导出器。
- 一个根级测试工作流；子目录保留的工作流仅作历史参考，不会在根仓库触发。

源格式：节点 URI、Base64 节点订阅或基础 Clash YAML。统一入口还支持上述基础 Clash YAML，但不支持其他完整客户端配置。HTTPS源在访问订阅时刷新，直接粘贴节点则保存为快照。VLESS可以透传给支持的客户端，但不意味着能转换到Surge。

## 独立部署说明（不要覆盖旧项目）
需要 Linux、Python 3.10+、systemd 和独立 HTTPS 路径。建议：
- 程序 /opt/proxy-import-hub
- 状态 /var/lib/proxy-import-hub（700，运行用户所有）
- 网关监听 127.0.0.1:8773
- 新 subconverter v0.9.0 引擎监听 127.0.0.1:25502
- 环境文件 /etc/proxy-import-hub.env（600，不入Git）

1. 创建独立无登录权限用户 proxy-import-hub，将本仓库放到程序目录，创建venv并安装 requirements.txt。
2. 下载 [subconverter v0.9.0](https://github.com/tindy2013/subconverter/releases/tag/v0.9.0) 对应平台发行包，放在新程序目录的 engine/；保留许可证。不要复用或修改线上旧引擎目录。
3. 复制 apps/surge/pref.ini 到新 engine/pref.ini，**把端口25501改为25502**。创建 engine/input，权限700且由新用户拥有。
4. 在新的600环境文件设置 SUB_PUBLIC_URL（例如 https://YOUR-DOMAIN/import）、SUB_ADMIN_KEY（随机长密钥）、SUB_ENCRYPTION_KEY（Fernet密钥）、SUB_DENIED_IPS（服务器公网IP）。用 Python secrets.token_urlsafe(32) 和 Fernet.generate_key() 生成，不使用示例密码。
5. 为新网关和引擎创建独立systemd单元。参考 apps/surge 的单元，但必须改用户、环境文件、目录、服务名称；网关从根目录运行 uvicorn server:app --host 127.0.0.1 --port 8773 --no-access-log --log-level critical。引擎保持仅回环网络隔离。不要直接启用子目录的旧服务名。
6. 在已有HTTPS server内新增 /import/ location，proxy_pass http://127.0.0.1:8773/，关闭该路径access/error日志、设置请求限流和2MB请求限制。**不修改原listen/default_server**。先备份、nginx -t，通过再reload。
7. 检查未授权 /api/shares 返回401、假令牌返回404、三个客户端备用导入流程和旧网站。

本次只归档新项目，没有执行以上部署操作。

## 私密信息与朋友账号
- 不包含真实节点、密码、订阅地址、运行数据库或服务器域名配置。
- 所有分享链接和订阅链接都是访问凭据，拿到链接即可读取节点。
- 撤销分享使网页和所有导入入口失效，但不能删除别人已经下载的节点密码。给朋友最好使用3x-ui独立客户端账号。
- 源内容加密存数据库，运行时转换临时文件仍可能短暂含明文；异常退出可能需要清理。数据库和加密密钥需分别安全备份。
- 继承的公网HTTPS获取逻辑会校验并固定DNS地址、限制大小，不允许任意内网目标。引擎应通过systemd限制对外联网。
- 当前没有过期自动撤销、额度管理或自动创建3x-ui账号功能。
